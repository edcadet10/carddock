# Security and data-safety reports

Report ordinary bugs through GitHub Issues using synthetic examples and redacted logs.
For an exploitable vulnerability or a reproducible data-loss issue, use this repository's **Security → Report a vulnerability** option when available. Do not attach private photos, access tokens or unredacted personal paths.

The current public version is the supported version. This is a volunteer project without a guaranteed response time. Keep separate backups and consult `docs/SAFETY.md` for the actual guarantees and limitations.
