# Changelog

## 0.1.0 — 2026-10-23

First public release of CardDock.

- Native macOS interface with light/dark appearance, folder selection and remembered locations.
- Daily/nested date folders, shoot labels and media filters.
- Verified original-file copies with collision-safe placement and content-based duplicate checks.
- Read-only preview and recovery for missing/changed destination copies.
- Originals kept by default; optional two-step confirmed deletion with fresh verification.
- Separate self-contained Apple Silicon and Intel downloads with bundled Python.

Known limits: non-notarized first-launch prompt; filesystem-date fallback for some formats; no RAW rendering or universal camera-package handling. See `docs/SAFETY.md`.
